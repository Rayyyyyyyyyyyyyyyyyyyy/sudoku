## 實機飛航紀錄

本機預檢已通過：Chrome 安裝 production build 後停止 preview，確認連線失敗，再以原生重新載入顯示文本與像素圖，並可開始遠征及推進第一個選擇。這份紀錄不代替下列實際攜帶裝置、完整關閉冷開與 60 分鐘驗收。

每台目標裝置記錄 HTTPS／localhost 來源、online 首載時間、service worker installed／activated／controlled、precache 完整性。之後關閉 Wi-Fi 與行動網路，確認原典外連失敗，完整關閉瀏覽器／應用，再由同一 `/#/rpg` 冷開。檢查新文本、像素圖、五個戰鬥按鈕、專精、遺物與恢復畫面。

分別在圍困夜間、已抽事件／掉落、已選專精／遺物、守龍已有準備四類 checkpoint 保存並關閉，重開後記錄 nodeId、資源、專精、裝備、prepared、PRNG value/calls，送出固定行動並與不中斷對照。另完成一次連續 60 分鐘斷網遠征、結算與新局，以及 v1 安裝更新至 v2 後的確認／取消轉換。不得把 build precache test 當作實機冷開證據。

- 擴寫有效：六人 v2 有效時間中位數 ≥120 分、個人 v2−v1 差值中位數 ≥30 分、至少 4/6 自願第二趟且第二趟新內容 ≥30%、投入度中位數 ≥4/5。

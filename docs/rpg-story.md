## 序章・無眠之地｜第三個沒有夢醒的清晨

阿拉修里昂的鐘響了七次，廣場仍然沒有人。窗板後傳來低低的數數聲；村民靠數到天亮，確認自己還醒著。你在井邊看見一個孩子，緊握著早已熄滅的蠟燭。

北方領主的年輕兒子曾往沼澤尋找一把劍，如今道路封閉，消息斷絕。村中法師把最後一封求援信交給你。蠟封上印著一座不可能存在的白色堡壘。

「別答應我一定回來，」他說。「答應我，進去以前，先弄清楚自己拿的是什麼。」

## 序章・無眠之地｜唯一能穿過夢的鋼

節點：`briefing`。

法師翻開一本燻黑的書。加茲納克乘著彗星而來，讓人的恐懼替他築城。鋼鐵攻不破他的要塞，尋常咒語也無法喚醒被困在夢裡的人。

只有薩克諾斯。那並非已經掛在某位國王腰間的名劍，而是鐵脊龍鱷背上的一條異鋼。村中鐵匠能將牠的外殼熔去，留下劍身；一隻鋼眼磨出劍鋒，另一隻則嵌進劍柄。

法師攤開兩件東西：一枚縫著銀線的護符，以及裝滿乾糧的布袋。「背包有限，自己選吧。能帶回來的見聞，也會幫到下一個出發的人。」

選項：

- **帶上守夜護符**：獲得護符；稍後可換取一條安全通路。 → `crossroads`；效果：取得物品：守夜護符
- **帶上乾糧與藥**：補給 +2、療傷藥 +1。 → `crossroads`；效果：補給 +2、取得物品：療傷藥

改編來源（sacnoth）：彗星巫師、龍鱷異鋼與兩顆鋼眼依原作；二選一補給為遊戲設計。

## 第一章・北方沼澤｜兩條離村的路

節點：`crossroads`。

森林在岔路口分開。左邊的木橋通往獵人的營地，橋前停著一輛翻倒的貨車；右邊是被樹根推歪的古老路碑，箭頭指向一座廢棄禮拜堂。

從這裡仍能看見村裡法師塔上的燈。你調整肩帶，給自己留了一條能回家的路。

選項：

- **走木橋，查看貨車**：人物事件：可能交換物資與消息。 → `bridge`
- **進入廢棄禮拜堂**：探索事件：尋找符文與古老的記錄。 → `ruins`

改編來源（original）：村莊到沼澤間的分支旅途。

## 第一章・北方沼澤｜車輪下的銅鈴

節點：`bridge`。

商人正試著把斷軸塞回車底。你走近時，他忽然把手中的扳手藏到背後，直到看清你的影子才鬆開肩膀。

「昨夜有個東西，借我的聲音在橋下喊救命。」他敲敲銅鈴，聲音清脆。「這是真的。餓也是真的。若你有吃的，我拿錢和一個消息換。」

選項：

- **分給他一份乾糧**：消耗補給 1；金幣 +3，記住商人的善緣。 → `ferryman`；條件：補給至少 1；效果：補給 -1、金幣 +3、取得線索：merchant、經驗 +2
- **沿河找一條安全的小徑**：遊俠專屬：保存補給，獲得 2 經驗。 → `camp`；條件：職業：遊俠；效果：經驗 +2
- **確認方向後繼續前進**：不消耗資源。 → `camp`

改編來源（original）：商人、交換與後續報答均為新寫。

## 第一章・北方沼澤｜擺渡人只收還活著的名字

節點：`ferryman`。

商人所說的小徑在河邊終止。黑水中央泊著一艘窄船，船夫披一件綴滿魚骨的斗篷。他沒有槳，只把一根白木杖伸進水裡，船便逆著水流靠岸。

船頭還坐著一名赤腳朝聖者，懷裡抱著沒有神像的木龕。她說夢魘來臨後，河會偷走渡客的名字；若沒有人在對岸叫出那個名字，渡客就會跟著倒影繼續往下游走。

擺渡人伸出三根手指。「錢、歌，或一個願意替別人記住名字的人。」他腰間的小銅鈴沒有舌，卻在你注視它時輕響了一聲。

選項：

- **付兩枚金幣，請他渡你過河**：金幣 -2；得到無舌銅鈴與擺渡人的暗號。 → `camp`；條件：金幣至少 2；效果：金幣 -2、取得物品：送魂鈴、取得線索：ferryman、經驗 +1
- **替朝聖者記住她的名字**：護送她到對岸；取得朝聖者的祝福，但擺渡人收回銅鈴。 → `camp`；效果：取得線索：pilgrim、取得線索：ferryman、經驗 +2
- **謝絕交易，沿淺灘涉水**：生命 -3；保存金幣，趕在自己的倒影前上岸。 → `camp`；效果：生命 -3

改編來源（original）：擺渡人、無名朝聖者、奪名之河與無舌銅鈴皆為新寫，用以延展沼澤旅程。

## 第一章・北方沼澤｜沒有燃料的火盆

節點：`ruins`。

禮拜堂的屋頂漏著晨光。祭壇上有一隻冰冷的火盆，盆底的刻線卻仍泛著暗紅。你用刀尖撥開灰，露出一行提醒：火可以帶走，飢餓不能。

牆上畫著一條生滿鐵甲的巨獸。牠每次張嘴，口鼻周圍的刻痕就深一分；最厚的背甲上，反而沒有留下任何刀痕。

選項：

- **以魔力讀取餘燼刻紋**：魔力 -2；記下符文、龍鱷弱點，經驗 +2。 → `crypt`；條件：魔力至少 2；效果：魔力 -2、取得線索：rune、取得線索：weakness、經驗 +2
- **抄下壁畫，留下火盆**：辨識龍鱷弱點，不消耗資源。 → `crypt`；效果：取得線索：weakness

改編來源（original）：禮拜堂與符文原創；龍鱷的特殊弱點取材自原作。

## 第一章・北方沼澤｜月石照著墓中人的臉

節點：`crypt`。

祭壇後的石階通往地下。墓室裡沒有棺木，只有十二具披甲遺骸倚牆而坐，像一群等候命令太久的衛兵。第十三張石椅空著，椅背刻著與白色堡壘相同的塔形紋章。

一枚月白色寶石嵌在隊長的眉骨上。你伸手時，空椅裡站起一個半透明的人影；牠沒有臉，胸前卻留著一枚被劍剖開的軍印。牠用死者的聲音問你，究竟替哪一位主人持劍。

劍尚未鑄成，你只能以自己的名字回答。墓室的寒意隨那句回答聚攏，牆上十二具遺骸同時把頭轉向你。

選項：

- **拒絕跪下，迎戰墓室怨靈**：迎戰怨靈；勝利後從倒下的軍印旁離開。 → `camp`；遭遇：無名怨魂
- **補全軍印上的封縛紋**：法師專屬，魔力 -3；取得月石與舊軍印，經驗 +2。 → `camp`；條件：職業：法師、魔力至少 3；效果：魔力 -3、取得物品：月長石、取得線索：sigil、經驗 +2
- **承諾終結堡壘的徵召**：生命 -3；讓軍印記住你的血，取得月石與通行印記。 → `camp`；效果：生命 -3、取得物品：月長石、取得線索：sigil、經驗 +1

改編來源（original）：地下墓室、怨靈軍隊、月石與舊軍印為新寫；堡壘會徵召死者的設定延伸夢築城堡的意象。

## 第一章・北方沼澤｜獵人留下的灰圈

節點：`camp`。

火堆外有一圈細灰，灰上沒有腳印。營地的主人已經離開，卻把一束乾柴架在石頭上，像是知道還會有人需要它。

沼澤裡傳來鐘一樣的撞擊聲。每隔幾息，地上的水就顫一下。今晚你得決定，身上的力氣究竟要留給趕路，還是留給見到那東西的時候。

選項：

- **生火休整後出發**：補給 -1；生命 +12、魔力 +6（不超過上限）。 → `marsh`；條件：補給至少 1；效果：補給 -1、生命 +12、魔力 +6
- **削一根結實的榛木杖**：取得驅獸手段，對龍鱷的攻擊可無視護甲。 → `marsh`；效果：取得線索：staff

改編來源（sacnoth）：榛木杖取自原作；營地休整和戰鬥效果為改編。

## 第一章・北方沼澤｜會留下犁溝的腳印

節點：`marsh`。

蘆葦倒向同一個方向。爪印之間拖著一條深溝，水在裡頭泛出鐵鏽般的顏色。那不是船隻通過的痕跡。

你順著溝走到一座半沉的棚屋。門板上綁著布條，一隻手從縫裡伸出來，急急指向北面。鐘聲停了。

選項：

- **先打開棚屋**：援救事件：付出物資或體力，換取同伴的幫助。 → `rescue`
- **追蹤巨獸，觀察牠的步態**：掌握弱點；龍鱷戰傷害 +2。 → `crocodile`；效果：取得線索：weakness

改編來源（sacnoth）：金屬心跳、尾痕與受威脅村民依原作；棚屋救援原創。

## 第一章・北方沼澤｜門後還有兩個人

節點：`rescue`。

棚屋裡是一名採藥人和她的弟弟。門梁被巨獸的尾巴砸斷，卡住出口；他們已經在裡頭蹲了一整夜。

「牠用鼻子試探每一扇門，」採藥人說。「打背上沒用。讓牠抬頭，讓牠退。」她把一小包藥根推到門縫下。「你若願意幫忙，這就是我們能給的。」

選項：

- **用繩結卸下門梁**：遊俠專屬：救出兩人，獲得療傷藥與弱點情報。 → `crocodile`；條件：職業：遊俠；效果：取得線索：rescued、取得線索：weakness、取得物品：療傷藥、經驗 +2
- **撬開門梁，扶他們出來**：生命 -4；救出兩人，獲得療傷藥與弱點情報。 → `crocodile`；效果：生命 -4、取得線索：rescued、取得線索：weakness、取得物品：療傷藥、經驗 +2

改編來源（original）：採藥人與她的弟弟為原創，救援會影響結尾。

## 第一章・北方沼澤｜鐵脊之下

節點：`crocodile`。

龍鱷伏在淺水裡，身體像一口被遺忘的熔爐。你抬起武器，牠也抬起頭。鼻端沾著鉛灰，眼睛則是兩點冷藍。

你記得法師的囑咐：與這樣的東西交手，蠻力只會消耗自己。先辨認牠準備怎麼動，再決定這一回合要進攻還是守住。

條件段落：

- 線索 `staff`：榛木杖抵住你的掌心。你已有迫使牠退卻的工具，攻擊能繞開厚甲。
- 線索 `weakness`：你已辨認吻端與轉身的破綻，本場每次攻擊額外造成 2 傷害。

選項：

- **迎戰鐵脊龍鱷**：回合制戰鬥；戰勝後帶回異鋼。格擋可恢復魔力。 → `forge`；遭遇：鐵脊龍鱷

改編來源（sacnoth）：原作以持杖阻止進食三日使龍鱷餓死；此處壓縮成有弱點的回合戰，不宣稱忠實重演。

## 第二章・有眼睛的劍｜爐火不肯吞下的東西

節點：`forge`。

鐵匠把帶回的金屬推進爐心。雜鐵先軟，外殼逐漸滴落，唯有中央那條異鋼紋絲不動。天將亮時，他用鋼眼磨完最後一道劍鋒。

另一隻眼睛嵌進劍柄。你握住它時，眼珠轉向門口；一個尚未敲門的村民正站在那裡。鐵匠笑了一次，隨即又疲憊地坐下。

## 第二章・有眼睛的劍｜最後一次有人替你開門

節點：`outfitter`。

補給鋪只剩一排藥瓶與幾塊硬餅。店主把價牌轉向你，沒有多說話。出村的路上已經有人開始搬運路障，準備抵擋今晚的東西。

## 第二章・有眼睛的劍｜堡壘每天換一條路

節點：`approach`。

白色尖塔明明就在正北，通往它的道路卻像活物般挪動。昨夜的溪谷長出荊棘，石堤則從沼水裡浮起，兩旁立著面朝城堡的斷首騎士像。

薩克諾斯的劍眼先看向林間，又轉向石堤，最後停在你背包側袋。它並不替你決定，只把每一條路將索取的代價一一指出。

遠處傳來獵犬的長嗥。城牆上的旗幟沒有風也在飄動，像有人已經知道你站在這裡。

條件段落：

- 線索 `ferryman`：你記得擺渡人的暗號：夢造的路總在第三個路標後說謊。石堤第二座雕像的影子因此顯得格外可疑。

選項：

- **穿過低語荊棘林**：路較短，但林中有被夢魘馴服的獵狼。 → `thornwood`
- **踏上斷首騎士石堤**：道路穩固；城堡的舊守衛仍在巡行。 → `causeway`
- **依測繪圖找出乾涸暗渠**：需要村莊的測繪桌；避開外圍威脅，直接抵達城門。 → `gate`；條件：村莊養成：失落路圖；效果：經驗 +2

改編來源（original）：會移動的道路、荊棘林、石堤與測繪捷徑為新寫，將永久養成帶回敘事分支。

## 第二章・有眼睛的劍｜狼群學會了說晚安

節點：`thornwood`。

荊棘上的每一片葉子都在低聲說話。它們借用村人的聲音勸你躺下：井水已經打好、門閂已經扣緊、明天再走也不遲。只有劍眼始終望著你身後。

第一頭狼踩著你的舊腳印出現，灰毛間纏著細小銀線。第二頭從樹根下爬出，嘴裡吐出一句屬於孩子的「晚安」。牠們的影子加起來，比狼本身多一頭。

林外就是堡壘前的裸岩。只要讓狼群失去夢魘的節拍，這片林子便攔不住你。

條件段落：

- 線索 `pilgrim`：朝聖者教你的短禱浮上心頭。狼嘴裡偷來的聲音頓時顯得空洞，不再像真正的呼喚。

- 線索 `ferryman`：擺渡人的窄船停在井旁，船底沒有沾一滴水。他把白木杖靠在門邊，說這趟渡資已經有人付清。
- 線索 `sigil`：舊軍印被掛進法師塔。午夜時，北方墓室的亡者卸下鎧甲，第一次沒有等候任何君王的命令。
- 線索 `prisoner`：獲救的鐘匠拆下塔頂那口失眠之鐘。他要把金屬重鑄成一座小鐘，只在真正的清晨響起。
- 線索 `choir`：孩子們很快學會那首被補完的歌。這一次，最後一個音落下之後，牆壁沒有移動，影子也都留在原處。

改編來源（sacnoth）：堡壘消失與村民安睡依原作；歸來互動和永久養成新寫。

## 遠征結束｜帶著路線回家

節點：`retreat`；結局：`retreat`。

你在還能選擇的時候轉身。森林把遠處的樂聲一層一層擋住，直到只剩下自己的呼吸。

法師沒有問你為什麼回來。他把地圖攤開，讓你指出走過的地方。這一趟的裝備會卸下，已帶回的見聞與村莊解鎖會留下。

改編來源（original）：主動撤退結局；不宣稱原作主角曾多次遠征。

## 遠征結束｜醒在最後一盞燈下

節點：`defeat`；結局：`defeat`。

最後記得的是劍眼轉向了黑暗。再睜眼時，你躺在法師塔下，手邊只有一張畫到一半的地圖。

這趟遠征已經失敗。有人把你拖回了林緣，卻沒能帶回你的行裝。你記住的路與見聞還在，可以先完成村莊養成，再重新出發。

改編來源（original）：失敗恢復與永久進度是 roguelite 改編設定。

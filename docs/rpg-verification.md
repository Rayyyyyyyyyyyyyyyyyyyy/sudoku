# RPG 骨架驗證

日期：2026-09-09。範圍：首版《夢魘堡壘》文本與可玩骨架，非三小時內容驗收。

## 已通過

- `npm run test:engine`：135 項既有引擎測試，包含離線 service worker 的預快取與導覽 fallback 單元測試。
- `npm run test:rpg`：21 項；三種職業各五種 seed 可完成主線，並覆蓋新墓室、石堤、畫廊、囚室、禁書庫與永久地圖路線；同時驗證資源門檻、三種異象、遺物、六項永久養成、戰鬥中保存續玩、動作 revision 防重複及存檔結構。
- `npm run test:ui`：31 項（其中 RPG 7 項）；包含異象與擴充養成呈現，以及讀取暫時失敗時即使寫入功能正常，也不覆寫原存檔的回歸測試。
- `npm run typecheck`、`npm run build`、`git diff --check`。
- 正式 build 的本機預覽：開始遠征、故事選項、重新載入保留原場景。
- 桌面與 360px 寬度視覺檢查；360px 下文件寬度與捲動寬度皆為 360，沒有橫向溢出。

## 尚未驗收

- 真正斷網後重新開啟：在 Codex 內建瀏覽器關閉本機 preview server 後重新載入，頁面呈空白；恢復 server 後可正常續玩。此結果不能當作離線載入成功，也尚未確認是瀏覽器支援或快取生命週期因素。
- 遊戲引擎和文本沒有執行時網路依賴，建置沿用既有 service worker 打包；但飛行前仍須在實際使用的瀏覽器完成載入，再以飛航模式重新開啟、操作及續玩驗收。
- 三小時耐玩度、完整隨機地圖、多輪內容差異與長期平衡，均不在本次短篇骨架的已驗證範圍。

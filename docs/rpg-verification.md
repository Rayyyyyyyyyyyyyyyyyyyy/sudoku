## 已通過

- `npm run test:engine`：135 項既有引擎測試，包含離線 service worker 的預快取與導覽 fallback 單元測試。
- `npm run test:rpg`：23 項；三種職業各五種 seed 可完成主線，並覆蓋四種荒野事件、四種夢城事件、兩組掉落、事件中途保存續玩、不重複唯一遺物及掉落耗盡補償；原有墓室、石堤、畫廊、囚室、禁書庫、異象與永久養成路線仍在回歸範圍。
- `npm run test:ui`：32 項（其中 RPG 8 項）；包含本機像素圖集路徑與職業圖示的可存取名稱、異象與養成呈現，以及讀取暫時失敗時不覆寫原存檔的回歸測試。
- `npm run typecheck`、`npm run build`、`git diff --check`。
- 正式 build 已包含 `assets/rpg-pixel-atlas.png`，且產生的 `service-worker.js` 明列該 PNG 於預快取清單；遊戲畫面不會向外站抓取圖片。
- 正式 build 的本機預覽：開始遠征、故事選項、重新載入保留原場景。
- 桌面與 360px 寬度視覺檢查；360px 下文件寬度與捲動寬度皆為 360，沒有橫向溢出。

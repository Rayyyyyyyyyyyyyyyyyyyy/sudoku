# 《夢魘堡壘》原典文本參照

查核日期：2026-09-09。

本文件保存《夢魘堡壘》後續改編應回查的一手文本位置、原作設定與現行遊戲對照。
它不是遊戲文本的第二份維護來源，也不是現代中文譯本；可執行繁中內容仍以
[`src/data/rpg/story.ts`](../src/data/rpg/story.ts) 為準。

## 一手文本

- 作者：Lord Dunsany（Edward John Moreton Drax Plunkett，1878–1957）。
- 篇名：*The Fortress Unvanquishable, Save for Sacnoth*。
- 收錄：*The Sword of Welleran and Other Stories*。
- 版本：[Project Gutenberg eBook #10806 完整 HTML](https://www.gutenberg.org/cache/epub/10806/pg10806-images.html)。
- 書目：[Project Gutenberg #10806](https://www.gutenberg.org/ebooks/10806)。發布於 2004-01-01，
  電子版最近更新於 2024-11-03，製作者為 Tom Harris。
- 正文定位：上述 HTML 的第 612 行為篇名，第 613 行開始故事，第 792–797 行為傳說／熱病的歧義尾聲，
  第 798 行進入下一篇。行號是 2026-09-09 查核時的 Gutenberg HTML 閱讀器位置，版本更新後可能移動。

Gutenberg 書目標示此電子書在美國屬公共領域；這不是全球權利判定。臺灣與素材使用邊界另見
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md#text-rpg-literary-source)。本專案不得把現代中譯、
後來插畫或其他改編作品當作同一公共領域來源。

## 原作固定設定

後續若宣稱「取自原作」，應遵守以下基線；若改動，須在節點 `provenance.note` 明說是改編。

### 人物與存在

- **Leothric**：Lorendiac 的兒子，二十歲，是原作唯一明確主角；不是三職業之一，也沒有永久養成。
- **Lorendiac**：Allathurion 的領主。原作只提供親屬與領主關係，沒有遊戲中的任務系統。
- **村中魔法師**：查閱 *Book of Magicians*、辨認 Gaznak 與說明 Sacnoth 的人；原作沒有名字。
- **Gaznak**：來自星間、乘彗星造訪的強大魔法師。每二百三十年來到地球一次，以自己的夢形成堡壘，
  並放出惡夢侵食人的心智。
- **Tharagavverug**：北方沼澤的龍鱷；背為鋼、腹為鐵、脊上藏著異世鋼條 Sacnoth，鼻子是鉛。
- **Thok、Lunk**：深淵道路上的兄弟龍；前者戰死，後者逃走。
- **Wong Bongerok**：Gaznak 最忠誠的守龍，長而低矮、擅長以裝甲蠍尾越過頭頂偷襲。
- **魔法樂師**：以弦樂維持 Gaznak 的睡眠、夢造建築與死亡咒；原作沒有逐一命名。

### 物件與魔法規則

- **Sacnoth** 不是預先鑄好的古劍，而是 Tharagavverug 脊上的不可熔、不可刮傷之異世鋼條。
- 一顆龍鱷鋼眼磨成劍鋒而耗盡，另一顆嵌進劍柄，能警戒、引路及識破守龍佯攻。
- Tharagavverug 不能被刀劍、火或水殺死，只能被阻止進食三天；榛木杖敲擊鉛鼻能迫使牠退後。
- Gaznak 只有 Sacnoth 能殺，但其鎧甲連 Sacnoth 也不能破。他會抓著頭髮把頭抬離脖子閃避斬首；
  Leothric 最後斬斷抬頭的手腕，使頭與身體同時失去生命。
- 堡壘不是一般永久建築。Gaznak 的夢在樂聲中化為大理石空間；他死後，建築、深淵與道路一同消失。
- 原作尾聲刻意不確定：英雄傳說、熱病幻覺與人物從不存在三種解釋並列，沒有替讀者裁決。

## 現行遊戲明確新增

以下內容可繼續使用，但不能誤標為 Dunsany 原作設定：

- 無名玩家取代 Leothric，並可選戰士、法師或遊俠。
- Leothric／領主之子被改寫為失聯前驅；求援信、井邊孩子與玩家遠征是新情節。
- 擺渡人、無名朝聖者、奪名之河、橋邊商人、採藥人姊弟與墓室怨魂。
- 守夜護符、月石、餘燼／鎮鐵符文、盟約繩結、燭淚鏡、鐘匠、夢囚、禁書庫、反咒節奏。
- 荊棘林、墓地魔狼、空鎧騎士、會移動的道路、石堤、畫廊、囚層與四個夢城異事。
- 職業技能、回合制敵方意圖、生命／魔力／金幣／補給、等級、戰利品表、種子異象與村莊永久養成。
- 戰敗後被救回、重複遠征、見聞累積及多條安全繞行路線。

## 本輪後仍未使用、適合下一輪的原作素材

以下優先於繼續憑空增加設定，因為它們能擴充內容又維持原典辨識度：

1. **四十行失敗咒語**：咒語混合活語與死語、獵鯨呼喊、駱駝詛咒和象鳴，且每行押同一個怪韻；
   可改成法師研究、殘頁收集或反咒組合，但具體規則仍屬遊戲新增。
2. **Thok 與 Lunk**：拆回兩隻龍；擊倒、威嚇或放走其中一隻，讓另一隻在後段改變守衛配置。
3. **不可言說的鐵窗囚物**：保持不完全揭露，用聲音、影子與交易呈現，不必替原作空白補上唯一答案。

## 使用方式

- 查原作事實：先查本文件的行段，再回到 Gutenberg 英文正文。
- 寫繁中場景：只在 [`story.ts`](../src/data/rpg/story.ts) 修改，並替每節更新 `provenance`。
- 產生審閱稿：執行 `npm run rpg:text`，更新 [`rpg-story.md`](./rpg-story.md)。
- 新增原創內容：可沿用原作氣質，但不得以 `source: 'sacnoth'` 掩蓋新增人物、規則或因果。
- 引用原文：保持短句、標出來源；遊戲正文以自行改寫的繁體中文為主。
